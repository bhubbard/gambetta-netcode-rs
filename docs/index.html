📖 Gabriel Gambetta's Netcode Architecture in Pure Rust

1. Client-Side Prediction

Local player inputs are applied immediately to the local predicted state without waiting for the server round-trip. Every input is recorded in a circular buffer with a sequence number.

2. Server Reconciliation

The authoritative server simulates inputs in order and sends snapshots with the last processed sequence $S_{srv}$. The client discards inputs $\le S_{srv}$, snaps to server state, and reapplies all inputs $> S_{srv}$.

3. Remote Entity Interpolation

Remote entities cannot be predicted. Instead, snapshots are buffered and rendered 100ms in the past with linear or Hermite cubic spline interpolation, guaranteeing buttery smooth motion even over packet jitter.

4. Lag Compensation / Hitbox Rewind

When a client fires at $T_{shot} = T_{now} - \text{RTT}/2 - \text{render\_delay}$, the server temporarily rewinds all remote player colliders to that exact historical frame, runs raycasts, and restores current state.
